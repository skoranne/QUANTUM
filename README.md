Elimination of Dependent Memory Fetches (The Bandwidth Multiplier)The most expensive operation on a GPU is a global memory read.Dense Baseline: Evaluates the cost function $C(p) = \sum F_{i,j} D_{p_i, p_j}$. This is called "pointer chasing." Because $p$ changes entirely between candidate solutions, the memory access pattern is completely random.
